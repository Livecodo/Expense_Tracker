# ✨ Features

## 📊 Dynamic Expense Tracking

✔ Add daily expenses instantly  
✔ Delete expense records in real-time  
✔ Track:
- 📅 Date
- 🏷 Category
- 📝 Description
- 💵 Amount

---

## 🌍 Internationalization (i18n)

✔ Multi-language support  
✔ Locale-aware text rendering  
✔ Dynamic language switching

---

## 💱 Localized Formatting

Built using the powerful JavaScript `Intl API`.

Supports:
- 💲 Currency formatting
- 🔢 Number formatting
- 📈 Percentage formatting
- 📆 Regional date formatting

---

## ✅ Live Form Validation

Interactive contact form with:
- Real-time validation
- Custom error messages
- Live preview
- Smooth hover effects

---

## 📱 Responsive Design

Optimized for:
- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

---

## 🧠 Personal Finance Guidance

Includes budgeting concepts like:

### 💡 50 / 30 / 20 Rule
- **50%** → Needs
- **30%** → Wants
- **20%** → Savings

Helping users build smarter spending habits.
